# Productos de Limpieza L & A

Proyecto entregable de HTML y CSS.

## Propuesta

- **Negocio:** Productos de Limpieza L & A
- **Para quién:** vecinos del barrio que quieren pedir sin escribir por WhatsApp
- **Qué necesita el cliente:** mostrar productos, precios y horarios
- **Forma de pago:** transferencia virtual
- **Dirección:** Calle 13C # 12-03, Villas de Don Juan
- **Horario:** 8:00 a.m. a 12:00 m. y 2:00 p.m. a 6:00 p.m.
